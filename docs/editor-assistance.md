# Editor assistance · 0.2.0

The existing two-file workspace remains the boundary. `completion.rs` owns a bounded static-analysis request; `suggest.rs` owns native presentation, a 280 ms debounce and one outstanding worker per editor. Source, companion file, active file, lesson/stage identity and Unicode character cursor form the exact snapshot. Results that no longer match are discarded. File changes, edits, selection, execution and focus loss dismiss incompatible suggestions.

The native editor keeps its existing undo stack. Tab/Enter accept a selected suggestion, Up/Down move through choices and Escape dismisses. A Suggest button and Ctrl+Space request assistance explicitly. The popup follows the caret, stays within the window and exposes the selected suggestion's description. Completion changes the draft and invalidates existing pass evidence in the same way as typing; only Check can grant completion.

The adapters parse trusted local practice text without evaluating learner modules. TypeDojo uses the pinned TypeScript language service with a closed in-memory two-file host and declaration-library reads only. PyDojo uses Jedi Script with an explicit isolated project and in-process inference, educational file/network/process guards and pinned pure-Python packages. No AI API, account, telemetry, learner uploads, arbitrary packages or npm/pip installation at runtime is involved. These tools are educational assistance, not adversarial code sandboxes.

Worker inputs are limited to 128 KiB per file. Queries have a five-second deadline, bounded output, private temporary folders, a clean environment and cleanup on every result. Tool failure leaves the draft unchanged; explicit requests display a retry notice. Suggestions never insert imports or multi-line snippets automatically. Static inference may be incomplete while typing invalid syntax. This is completion assistance, not a full VS Code/LSP implementation.

Bundled tool manifests pin versions, upstream URLs and SHA-256. Archives are verified before extraction; licenses ship with the runtime. Developer tool overrides remain explicit. No progress schema migration. Validate language queries with the real adapters (inference, sibling exports, Unicode spans, incomplete words and non-execution), run required repository gates, then review keyboard acceptance, Undo/Redo, dismissal, switching and wide/compact layouts manually. Do not add automated presentation tests.
