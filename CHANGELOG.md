# Changelog

## 0.1.0 — 2026-11-15

- Introduce 53 TypeScript lessons, each with a structured reading, separately graded guided exercise and independent lab.
- Add original course artwork, syntax highlighting, saved drafts, explanations, predictions, hints and worked solutions.
- Check answers with the strict TypeScript compiler and runtime examples in selected labs.
- Provide a two-file focus workbench with Run, V8 Inspector debugging, breakpoints, stepping, variables, expression evaluation, logs and compiler problems.
- Bundle offline Prettier 3.6.2, with Format, Undo/Redo and safeguards against stale formatting results.
- Ship an ad-hoc signed macOS Apple Silicon app, SHA-256 checksums and the Keiko installation contract.

Node.js 22.13+ and TypeScript 5.9+ are required separately. This initial curriculum does not constitute a complete professional qualification; see ROADMAP.md for additional coverage. The interactive VM is intended for trusted local learning code and is not a hostile-code sandbox. The app is not notarized.
